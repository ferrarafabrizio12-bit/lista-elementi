
# Lista Elementi

Una semplice applicazione web sviluppata con React e Vite per gestire una lista di elementi, con descrizioni, completamento e filtri.

## Funzionalità

- Aggiunta di elementi con testo e descrizione.
- Validazione dei campi del form.
- Completamento e cancellazione degli elementi.
- Filtraggio tra tutti gli elementi, quelli da completare e quelli completati.
- Salvataggio dei dati in `localStorage`.
- Gestione dello stato con `useReducer`.
- Condivisione delle funzioni tramite `useContext`.
- Ottimizzazione dei filtri con `useMemo`.
- Gestione del focus con `useRef`.
- Gestione asincrona dell'invio del form.

## Tecnologie utilizzate

- React
- JavaScript (JSX)
- Vite
- HTML e CSS
- Git e GitHub

## Installazione

Per eseguire il progetto in locale:

1. Clona il repository:

   ```bash
   git clone https://github.com/ferrarafabrizio12-bit/lista-elementi.git
   ```

2. Entra nella cartella:

   ```bash
   cd lista-elementi
   ```

3. Installa le dipendenze:

   ```bash
   npm install
   ```

4. Avvia il server di sviluppo:

   ```bash
   npm run dev
   ```

5. Apri nel browser l'indirizzo mostrato nel terminale.

## Obiettivo del progetto

Questo progetto nasce come esercizio pratico per approfondire React, la gestione dello stato, gli Hook e la struttura dei componenti, consolidando progressivamente le basi dello sviluppo frontend.
